# Erlang Language

Syntax highlighting for Erlang.

- Grammars: `erlang`
- File types: `erl`, `hrl`, `app.src`, `app`, `escript`, `rebar.config`, `sys.config`
- License of the bundled grammar and queries: Apache-2.0

The Tree-sitter grammars are compiled to WebAssembly from pinned sources.
`PROVENANCE.md` lists the sources and `licenses/` carries their licenses.
