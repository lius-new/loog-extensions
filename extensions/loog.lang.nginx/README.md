# Nginx Language

Syntax highlighting for Nginx.

- Grammars: `nginx`
- File types: `nginx`, `nginx.conf`
- License of the bundled grammar and queries: MIT

For other Nginx configuration files ending in `.conf`, choose Nginx from the syntax highlighting menu.

The Tree-sitter grammars are compiled to WebAssembly from pinned sources.
`PROVENANCE.md` lists the sources and `licenses/` carries their licenses.
