# Aura Themes

Color themes for Loog, next to the built-in **Aura Dark**.

- **Aura Light** is a clean light theme with an indigo accent.
- **Ember** is a warm stone-and-ember dark theme.
- **High Contrast** has a black background, bright text and strong borders.

Choose one in the command palette (**Ctrl+Shift+P**, then the color theme command).
A theme changes colors only; how the editor behaves does not change.

## Make your own

A theme is one small JSON file that starts from a built-in theme and names what
it changes. The files in `themes/` list every color, so they also show what can
be changed.
