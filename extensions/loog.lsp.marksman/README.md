# Marksman Language Server

Markdown link completion and navigation powered by Marksman.

Open a supported file in a trusted workspace to start the Loog WASM client.
The client uses the nearest `.marksman.toml` project or the open workspace folder.
The package contains a pinned native server for its platform.

The `configuration` and `initialization` extension settings accept JSON text.

See the [upstream server documentation](https://github.com/artempyanykh/marksman).
