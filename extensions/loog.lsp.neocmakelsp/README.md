# Neocmakelsp

CMake completion, navigation and formatting powered by Neocmakelsp.

Open a supported file in a trusted workspace to start the Loog WASM client.
The package contains a pinned native server for its platform.

The outermost `CMakeLists.txt` or `CMakePresets.json` in the open workspace
keeps files in nested CMake directories in the same project session.

The `configuration` and `initialization` extension settings accept JSON text.

See the [upstream server documentation](https://github.com/neocmakelsp/neocmakelsp).
