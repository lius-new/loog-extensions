# Buf Language Server

Protobuf diagnostics, completion, navigation and formatting powered by Buf.

Open a supported file in a trusted workspace to start the Loog WASM client.

The package includes a pinned Buf binary. Open a workspace containing
`.proto` files and use `buf.yaml` to configure module paths and lint rules.

See the [upstream server documentation](https://buf.build/docs/cli/editors-lsp/).
