# Vscode Langservers Extracted Language Server

The Vscode Langservers Extracted language server.

Extension package: 0.1.0. Upstream program: 4.10.0.

## Serves

- **HTML Language Server**: `html`
- **CSS Language Server**: `css`, `scss`
- **JSON Language Server**: `json`
- **ESLint Language Server**: `javascript`, `typescript`

Requires: `loog.runtime.node@^0.1.0`.

License: MIT. Platform: every supported platform.

Loog starts the server when you open a file it serves, and asks before running it the first time.
`PROVENANCE.md` records where the files came from and `licenses/` carries their licenses.
