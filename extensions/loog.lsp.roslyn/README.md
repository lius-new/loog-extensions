# Roslyn Language Server

C# completion, diagnostics and navigation powered by Microsoft Roslyn.

Open a supported file in a trusted workspace to start the Loog WASM client.
The package includes the pinned language server for its platform.

Install a .NET SDK that provides the .NET 10 runtime and can build your project.
Open the solution or project folder in Loog. Roslyn automatically loads a
solution or discovers C# projects in the workspace.

See the [upstream server documentation](https://github.com/dotnet/roslyn/tree/main/src/LanguageServer/roslyn-language-server).
