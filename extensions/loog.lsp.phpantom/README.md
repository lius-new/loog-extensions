# PHPantom

PHP completion, type information and navigation powered by PHPantom.

Open a supported file in a trusted workspace to start the Loog WASM client.
The package contains a pinned native server for its platform.

PHPantom indexes the project and includes PHP standard library stubs. The
nearest `.phpantom.toml` or `composer.json` selects the project root.

The `configuration` and `initialization` extension settings accept JSON text.

See the [upstream server documentation](https://github.com/PHPantom-dev/phpantom_lsp).
