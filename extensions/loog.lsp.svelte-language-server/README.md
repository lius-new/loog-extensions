# Svelte Language Server

Svelte diagnostics, completion and navigation with JavaScript and TypeScript support inside components.

Open a supported file in a trusted workspace to start the Loog WASM client.
The server runs through `loog.runtime.node`.

Install the project dependencies for module resolution and SvelteKit support.

The `configuration` and `initialization` extension settings accept JSON text.

See the [upstream server documentation](https://github.com/sveltejs/language-tools).
