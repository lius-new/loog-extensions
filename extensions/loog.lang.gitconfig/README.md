# Git Config

Syntax highlighting for Git configuration and submodule files.

- Grammar: `git_config`
- File names: `.gitconfig`, `gitconfig`, `.gitmodules`, and `gitmodules`
- License of the bundled grammar and queries: MIT

For a repository's `.git/config` or an included config file with a different
name, choose **Git Config** from the syntax highlighting menu.

The Tree-sitter grammar is compiled to WebAssembly from a pinned source.
`PROVENANCE.md` records the source and `licenses/` carries its license.
